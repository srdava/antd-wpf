Ant Design 的 WPF 实现

同一套设计 token、同一套组件语义，跑在 net48 与 net8-windows 上。零第三方依赖，536 个 token 与 antd 官方值逐个对拍。

net48net8-windows536 token 对拍847 图标无障碍 100%

快速开始

dotnet add package Antd.Wpf.Controls
<Application.Resources>
  <ResourceDictionary>
    <ResourceDictionary.MergedDictionaries>
      <ResourceDictionary Source="pack://application:,,,/Antd.Wpf.Controls;component/Themes/Framework.xaml" />
    </ResourceDictionary.MergedDictionaries>
  </ResourceDictionary>
</Application.Resources>
ThemeManager.Current.Attach(Application.Current.Resources);
ThemeManager.Current.Apply(ThemeConfig.CreateDefault());

// 中文文案 + 跟随系统的减动效
AntdLocale.UseCulture("zh-CN");
AntdMotion.UseSystemDefault();
