# Antd.Wpf 1.1.2

修复 Select 下拉面板的样式与定位问题。

## 修复

| 问题 | 原因 | 处理 |
|---|---|---|
| 下拉面板只有 48px 宽，远窄于字段 | 面板没有宽度约束，宽度跟着最窄的条目走 | 面板 `MinWidth` 绑定字段 `ActualWidth` |
| 面板整体右移、与字段左边缘不对齐 | 为阴影预留的 16px 外边距把内容推开了，但定位没有补偿 | 用 `RenderTransform(-16,-16)` 抵消外边距，再在开层后实测偏差并折算进 Popup 偏移（最多迭代 3 次收敛） |
| 面板顶边与字段重叠 7～13px | 同上，垂直方向的补偿值算错 | 同上，最终稳定在字段下方 4px |
| 长列表高度 | 未变 | `MaxDropDownHeight=256` + 虚拟化滚动正常 |

## 新增断言

- 面板宽度等于字段宽度（±1.5px）
- 面板左边缘与字段左边缘对齐（±1.5px）
- 面板位于字段下方 4px（±2.5px）
- 20 项时出现可滚动区域，高度不超过 `MaxDropDownHeight + 40`

## 关于阴影

阴影仍由 `Antd.Effect.Popup`（Blur 14 / Depth 3）绘制。抓取弹层需要真实窗口句柄，
自动化只能验证几何，**阴影的观感需要人眼确认一次**。

## 升级

```bash
dotnet add package Antd.Wpf.Controls --version 1.1.2
```

纯修复，无 API 变更。
